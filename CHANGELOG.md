# Changelog

All notable changes to this project are documented here. The format follows Keep a Changelog, and versions use Semantic Versioning.

## [0.1.0] - 2026-09-03

### Added

- Clean-room, standard-library publishing QA pipeline
- Source and claim registers with SHA-256 provenance
- Reproducible CSV-backed claim checks
- Offline fixture-based link validation
- Accessible standalone HTML rendering
- Deterministic QA report, traceability exports, release manifest, and checksums
- Positive, negative, determinism, and tamper-detection tests
