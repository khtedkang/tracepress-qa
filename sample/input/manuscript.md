# Harbor Notes

> A miniature evidence-led publication built from an entirely fictional catalog.

## Demonstration status

Harbor Notes is a portfolio demonstration, not a report about a real harbor, collection, organization, or field study. Every record and result is synthetic. The example uses a [reserved example link](https://example.com/) so link behavior can be tested without treating a live page as evidence.

## Method

The workflow separates source registration, claim registration, manuscript review, rendering, and release packaging. The demonstration validates declared link fixtures without making live network requests. [claim:C-004]

## Limits and disclosure

Passing checks establish internal consistency within the demonstration fixtures; they do not establish external truth or production readiness. The renderer supports only a deliberate Markdown subset, and the link checker uses declared offline responses.

This sample was created with AI-assisted coding under human direction and review. It includes no confidential material, company source code, internal prompt, manuscript, customer identity, proposal, correspondence, or operational analytics.
